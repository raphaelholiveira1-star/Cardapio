# Lanchonete Praça 12 | Cardápio digital (projeto de demonstração)

Cardápio digital fictício de uma lanchonete, com pedido enviado direto pelo WhatsApp. Foi criado para demonstrar como um pequeno negócio pode receber pedidos sem app, sem cadastro e sem pagar taxa por pedido. Não é uma lanchonete real.

## O que o projeto faz

- Cardápio organizado por categorias (lanches, porções, bebidas e sobremesas), com menu de navegação rápida
- Botões de adicionar e ajustar a quantidade de cada item
- Barra fixa com o total do pedido, sempre visível no celular
- Tela do pedido com nome, retirada ou entrega (com endereço e taxa), forma de pagamento (Pix, cartão ou dinheiro, com campo de troco) e observações
- Envio do pedido pelo WhatsApp, já escrito e organizado, com itens, valores, total e dados de entrega
- Layout pensado primeiro para o celular, com tema claro e escuro conforme o aparelho

## Como abrir

1. Baixe ou clone esta pasta.
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada. Mantenha o `index.html` e o `style.css` na mesma pasta.

## Tecnologias

HTML, CSS e JavaScript puros, sem bibliotecas e sem imagens externas.

## Como seria em um projeto real

Nesta versão o cardápio está fixo no código e o pedido é só uma mensagem de WhatsApp. Em um projeto de verdade, o dono poderia editar o cardápio e os preços por um painel, marcar itens como esgotados, e o pagamento por Pix poderia ser gerado e confirmado automaticamente por um serviço de pagamentos.
